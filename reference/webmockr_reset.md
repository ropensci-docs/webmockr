# webmockr_reset

Clear all stubs and the request counter

## Usage

``` r
webmockr_reset()
```

## Value

nothing

## Details

this function runs
[`stub_registry_clear()`](https://docs.ropensci.org/webmockr/reference/stub_registry_clear.md)
and
[`request_registry_clear()`](https://docs.ropensci.org/webmockr/reference/request_registry.md) -
so you can run those two yourself to achieve the same thing

## See also

[`stub_registry_clear()`](https://docs.ropensci.org/webmockr/reference/stub_registry_clear.md)
[`request_registry_clear()`](https://docs.ropensci.org/webmockr/reference/request_registry.md)
